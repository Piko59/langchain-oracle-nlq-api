
# LangChain Oracle Agent API

This project provides a FastAPI application that allows users to query an Oracle database using natural language questions. It leverages LangChain's SQL Agent and OpenAI's GPT-4 model to understand the questions, interact with the database, and return relevant answers.

## Features

* Query an Oracle database using natural language.
* Utilizes LangChain's `SQLDatabaseToolkit` and `create_sql_agent` for database interaction.
* Uses OpenAI's `gpt-4` model for natural language understanding.
* Built with FastAPI for easy API deployment.
* Dockerized for simplified setup and deployment[cite: 1].

## Technologies Used

* Python
* FastAPI
* LangChain
* OpenAI API
* Oracle Database
* Docker [cite: 1]
* Uvicorn
* Oracledb driver

## Setup Instructions (Docker)

1.  **Prerequisites:**
    * Docker and Docker Compose installed.
    * An existing Oracle database running.
    * An external Docker network (`oracle-network` in this case) that the Oracle database container is connected to[cite: 1]. Adjust `docker-compose.yaml` if your network name differs.
    * An OpenAI API Key.

2.  **Clone the repository (Optional - if you were to put this code in a repo):**
    ```bash
    git clone <repository_url>
    cd langchain-oracle-agent-api
    ```

3.  **Configure Environment Variables:**
    Update the `environment` section in the `docker-compose.yaml` file with your actual Oracle database credentials and OpenAI API key[cite: 1]:
    ```yaml
    environment:
      - ORACLE_USER=<Your_Oracle_Username> # e.g., C##PARKING [cite: 1]
      - ORACLE_PASSWORD=<Your_Oracle_Password> # e.g., MyPassword123 [cite: 1]
      - ORACLE_DSN=<Your_Oracle_DSN> # e.g., oracle-xe/XE [cite: 1]
      - OPENAI_API_KEY=<Your_OpenAI_API_Key> [cite: 1]
    ```
    *(Note: For production, consider using more secure methods for handling secrets, like Docker secrets or environment files.)*

4.  **Build and Run the Docker Container:**
    ```bash
    docker-compose up --build -d
    ```
    This command builds the Docker image based on the `Dockerfile` (implicitly using the current directory `.` [cite: 1]) and starts the `langchain-api` service in detached mode. The API will be accessible on port 8001 of your host machine[cite: 1].

## Usage

Send a POST request to the `/query` endpoint with a JSON payload containing your natural language question.

**Endpoint:** `POST /query`

**Request Body:**
```json
{
  "question": "Your natural language question about the database"
}
Example using curl:

Bash

curl -X POST "http://localhost:8001/query" \
-H "Content-Type: application/json" \
-d '{
  "question": "How many tables are in the database?"
}'
Response:
The API will return a JSON object containing the answer generated by the LangChain agent.

JSON

{
  "response": "The agent's response based on the database query."
}
Logging
The application includes basic logging to the console for received questions, agent results, and errors.

Main Application Logic (main.py)
The main.py script:

Initializes a FastAPI application.
Configures logging.
Establishes a connection to the Oracle database using LangChain's SQLDatabase.
Sets up the OpenAI LLM (gpt-4).
Creates a LangChain SQLDatabaseToolkit and SQL Agent.
Defines a /query endpoint that accepts POST requests with a question.
Uses the agent to run the question against the database.
Returns the agent's response or raises an HTTPException on error.
